# 🛒 E-commerce SQL Analytics Project

## 📌 Overview
This project analyzes an e-commerce dataset using SQL to derive actionable business insights related to sales, products, customers, and regional performance.

## 🧰 Tools Used
- MySQL

## 🔍 Key Analysis
- Sales Performance (total revenue, category-wise revenue)
- Product Performance (top-selling products)
- Customer Analysis (spending, high-value customers)
- City-wise Revenue Analysis
- Time-based Trends (monthly sales, running total)

## 🧠 Key Insights
- Chennai generates the highest revenue among all cities
- Adidas T-shirt, Nike Shoes, and Bed are top-selling products
- Sales are concentrated in metro cities like Chennai, Hyderabad, and Bangalore
- High-value customers contribute significantly to total revenue
- Digital payments (UPI) are the most preferred method
